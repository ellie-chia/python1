Example of python code, student management system. The aim of the Student Management System was to create a program that could organise and manage student information. The code is structured into two main modules, student management system which holds functions that sort, create and recall data. The main module holds code that creates the display for the main menu where the user can select different options to go to different functions. In the student management system module, there are three main sections of the code. Each section is split into 4 smaller functions which will be further described in the code description. The first section focuses on student information. Firstly in the student class function each variable, ‘student_id’, ‘first_name’, ‘last_name’, ‘email’ and ‘unit_id’ were defined as strings or integers. Next in the student data function, a number of preexisting students were added to the database. Each entry of data is kept in accordance with the correct string and integer defined beforehand in the class. This is followed by a function which inserts new student information into the database. The code prompts the user to supply the new students id, name, email and unit id. It then checks if the ‘student_id’ and ‘unit_id’ are numbers. If they are, it inputs the new information into the database which can be recalled later. If not, it prints an error statement that some information was not using the correct alphanumerical character and asks the user to input that student into the system again. The last function in this section prints student information. By inputting a student’s id into the system the user will see the student’s information. If the student’s id does not exist, an error message will appear and the user will be redirected back to the main page.

The other two sections of my code in the student management system follow a similar format to the first section on students, but is performed with the unit and degree information.

In the section of my code that focuses on the unit information ‘unit_id’, ‘unit_name’ and ‘unit_credit’ is defined in the unit class. In the insert unit information function the code checks that the unit id and the unit credit are integers. If the user fails to input integers and characters in their respective place, an error message pops up and asks the user to input this information in the terminal again. This section of the code also has a function that defines preexisting data for units and a function that prints information when requested by the user.

In the last section of the code, there are functions that sort and analyse degree information. Within the degree class the variables ‘degree_id’, ‘degree_name’ and ‘associated_units’ is defined. Like the other sections, there is a function that holds preexisting code for 4 degrees and their associated units. There is also a function that inserts new degree information into the database. This is done by checking that the degree id and the associated units are integers. If they are, the information is successfully loaded onto the memory, if not the input is rejected and an error message pops up asking for the user to input the degree information again.

In the main module, the code prints a welcome message and asks the user to select from the following options which will perform the respective functions. Choices 1-3 allow the user to view information on students, units and degrees. Options 4-6 let the user input new information into the database and option 7 closes the program. If a user inputs a non-numerical character or a number bigger than 7 or less than 1 it prints an error message and asks for the user to input a number again.
